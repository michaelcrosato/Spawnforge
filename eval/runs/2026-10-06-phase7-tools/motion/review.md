# Motion review

Each filmstrip (m01.png … m10.png) shows one of the tasks below: frames left to right,
then top to bottom, with the time on each frame and a footfall diagram or an event timeline
beneath. Names of creatures, gaits, actions and events are hidden. Match every filmstrip
to the task it shows; each task is used once. Write `motion-answers.json` beside this file:
`{ "m01": "<task id>", … }`.

| Task id | Task |
| --- | --- |
| quadruped-walk | A four-legged creature walking slowly |
| quadruped-trot | A four-legged creature trotting: diagonal legs move together |
| tripod | A six-legged creature in a tripod gait: three feet down at a time |
| slither | A legless creature slithering in S-curves |
| biped-walk | A two-legged creature walking |
| bite | Standing and biting at something just in front of it |
| roar | Standing and roaring with its head raised |
| look | Holding still and turning its head to look to one side |
| stalk-and-bite | Walking up to a marked point and biting it |
| course | Walking a winding route over bumpy ground |
